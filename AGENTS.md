# test-swarm

When the user says **test-swarm**, **`/test-swarm`**, **95% coverage**, or asks to raise JS/TS test coverage with parallel agents: read and follow `skills/test-swarm/SKILL.md` (or `~/.cursor/skills/test-swarm/SKILL.md` if this file is not in the repo). Default 10 workers; a number in the prompt wins.

Ask only which git branch to open PRs against. Then run the swarm. Do not merge. Do not change product code.
